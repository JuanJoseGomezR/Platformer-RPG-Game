# 🎮 Platformer RPG Game

A 2D platformer with RPG mechanics including combat, leveling, and inventory management.

---

## 🧠 Overview

This game is a side-scrolling platformer where the player explores levels, fights enemies, gains experience, and upgrades their character over time.

Core features include:
- ⚔️ Combat system (melee & ranged enemies)
- 📈 Leveling & XP progression
- 🎒 Inventory & equipment system
- 🧠 Multiple enemy AI behaviors (Melee, Tank, Ranged)

---

## 🎮 Controls

| Action        | Key          |
|--------------|-------------|
| Move         | A / D       |
| Jump         | Space       |
| Attack       | Left Click  |
| Inventory    | I           |
| Use Item     | Right Click |

---

## ⚙️ Features

### 🗡️ Combat System
- Different enemy types with unique behaviors
- Attack cooldowns and animations
- Projectile system for ranged enemies

### 📊 RPG Mechanics
- Experience points (XP)
- Leveling system
- Stat progression

### 🎒 Inventory System
- Grid-based UI
- Item tooltips
- Consumables and equipment

### 🤖 Enemy AI
- Patrol, Chase, and Attack states
- Type-based behavior system:
  - Melee enemies
  - Tank enemies
  - Ranged enemies

---

## 💾 Saving System
- Multi-slot save system (in progress / implemented)
- Player progression is stored and loaded

---

## 🧩 Technologies Used

- Unity (2D)
- C#
- Scriptable Objects (for items and data)
- Animator Controller (for character and enemy animations)
